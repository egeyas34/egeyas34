## 🏃 Heala: AI fitness coach for iPhone and Apple Watch

[heala.fit](https://heala.fit) · [App Store](https://apps.apple.com/us/app/heala-ai-fitness-coach/id6814499922) · *code is private*

Most people juggle one app for food, another for workouts, another for sleep and another for recovery. Heala puts nutrition, training, sleep, recovery and wearable data in one place, and an AI coach turns it into a clear answer to "what should I do today?"

- **Shipped in under six months.** Launched in October 2026 and reached **800+ downloads and 500+ sign-ups in the first two weeks**, with our first paying subscribers.
- **Product, UX and UI.** I came up with most of the features: the main dashboard, Fuel (nutrition and AI meal scanning), workouts, the AI coach, habits, cycle tracking and the cardio map. I built the interface with my co-founder in React Native and TypeScript, including the Cardio hub, a share-card studio and the Career page.
- **Heala Console.** An internal admin app in Next.js that we run the company from: sign-ups, retention, active users by plan, revenue and ad spend, a budget calendar and an issues queue.
- **Heala Creators.** A self-serve creator programme at heala.fit/creators, with sign-up, per-video rewards and a review queue.
- **Growth, in-house.** We run all marketing as a team of two: Meta Ads, Apple Ads and organic social. I make our video ads myself with AI tools.

`React Native` `TypeScript` `Expo` `Apple Watch` `Next.js` `Supabase` `Meta Ads` `Apple Ads`

## 📊 Datrix: an AI data analyst

*Prototype, built in two days · code is private*

Upload a CSV or Excel file and get what a data analyst would hand you: a profile of the data, the findings in plain English, the technical detail behind them, and a report you can send.

- A Python API profiles the data with **pandas** (descriptive statistics, correlations, skewness, missing values and duplicates), then **Claude** writes the findings twice: once in plain English and once with the technical detail.
- The API also answers follow-up questions about a dataset and builds **PDF** and **PowerPoint** reports with the sections you choose.
- Accounts, projects and file storage on Supabase; the API is deployed on Railway.

`React` `TypeScript` `Tailwind CSS` `shadcn/ui` `FastAPI` `pandas` `Claude API` `Supabase` `Railway`

## 🗓 Hub: one app for my whole year

A personal planning and study app I designed and built for myself.

- **Today:** three progress rings, one per area of my life, that fill with what I actually finished today. Daily routines, deadlines sorted by days left, and week, month and year calendar views.
- **Learn:** my own interactive courses in Python, JavaScript and TypeScript, SQL and machine learning, built from custom teaching components.
- **University:** all ten Year 2 modules, week by week, with a "flag to study" queue, notes for each week and a link to every page.
- **Light and dark themes**, with every text element checked against WCAG AA contrast in both modes across 44 page states.

`React` `Vite` `JavaScript` `CSS`
